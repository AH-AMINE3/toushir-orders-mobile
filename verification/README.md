# Mobile verification · 17 October 2026

The reports here contain sanitized evidence from the running .NET API and actual app interfaces. Credentials for isolated test actors stayed in process memory and the app's intended credential stores.

- `public-native-workflow-verification.json`: 6 checks on the earlier preview-signed courier APK against `https://toushir-commerce-staging.onrender.com`: real system-browser code/S256 login and native callback, assigned pickup, consented emulator GPS, quantity-bound partial receipt using the manual-code fallback, separate cash/change and real-account restoration after restart.
- `public-native-merchant-verification.json`: 3 checks on the earlier preview-signed merchant APK against the same public API: 2,500-product catalogue, a scoped merchant invitation opened through the native commerce scheme, and the joined session restored after restart.
- `public-apk-metadata.json`: verified package identities, HTTPS origin, public preview certificate fingerprint, ARM64 library architecture, Android SDK versions and APK hashes. Both APKs installed successfully on Android Emulator API36. The actual merchant capture confirms the final mint beverage and aqua fresh category colours.
- `packaged-workflow-verification.json`: 10 connected browser checks on the combined local application host at port 5860, before the final category-only colour correction (`16f74d91` bundle). That export was followed by the Ultra merchant account/headers/control finish; hosted verification is retained in the repository-level `verification/cloud-mobile` directory.
- `workflow-verification.json`: 10 connected browser checks, including RFQ, quote approval, pickup, quantity-bound partial receipt, separate cash/change, concurrent merchant/courier identities, messages, campaign preview and reward reservation.
- `oidc-ui-verification.json`: 3 actual Expo browser AuthSession checks: server login, S256 callback, API validation of the real driver JWT, rotating refresh restoration and no JavaScript runtime errors.
- `native-workflow-verification.json`: 6 Android Emulator API36 arm64 checks: real system-browser authorization, assigned pickup, consented Expo Location with an emulator-supplied GPS fix, manual receipt-code fallback, partial receipt and separate cash/change, SecureStore restoration after restarting the app.

`ios-verification.json` and the two iOS screenshots verify separate Release builds installed and running on iPhone 17 Pro / iOS 26.5. The merchant catalogue and courier manifest rendered from the API. iOS business interactions and system-browser PKCE were not executed because the native UI automation service could not start.

The GPS fix was supplied explicitly to the emulator; this is not evidence of a physical courier journey. Native receipt verification exercised the manual-code fallback. Physical camera scanning and real-device store distribution have not been tested by these reports.

The current signature-verified public Android APKs are in the repository's `downloads` directory and copied to `build/downloads/toushir-merchant.apk` and `toushir-driver.apk`. They target the HTTPS staging API. Files with `-local-emulator.apk` are separate historical local-only builds; do not share them as public phone previews. The supplied iOS Simulator archives target `http://localhost:5860` and predate the final category-only colour correction; rebuild commands for a hosted API are in the mobile README. Browser previews use same-origin requests and the `/mobile/auth/callback` callback.

The Ultra finish was verified in the actual browser previews, including the merchant account summary, point/card navigation, address form and communication consent. Both Android variants were recompiled and signature/origin/hash checked afterward. Their earlier native business-runtime reports keep their original timestamps; the refreshed APKs were not relaunched after the user requested browser-only simulators to preserve RAM. An extra iOS rebuild was stopped at the same request. Existing iOS local archives retain their stated earlier-build limits.
